# Timecode/clap fixture

Generated by `node tests/e2e/fixtures/recording-studio/generate.mjs` using FFmpeg 7.1.
Set `FFMPEG_PATH` to an installed FFmpeg binary if it is not on PATH.
The three small files describe an eight-second reference session:

| Source | Session offset (seconds) | Video | Audio |
| --- | ---: | --- | --- |
| screen.webm | 0 | 25 fps, VP8 | none |
| camera.webm | 0.37 | 30 fps, VP8 | Opus, 48 kHz |
| microphone.webm | 0.71 | none | Opus, 48 kHz |

Twelve top-row binary bands (least significant first) encode original session
time in hundredths of a second. The four visible digits show that integer.
A bottom white flash and 880 Hz, 60 ms audio pulse occur at integer session
seconds. Encoding delay/padding remains in the container; tests inspect timestamps.
These files contain no personal data and were generated for this repository.

The long-timeline test reuses these bytes in two explicitly mapped segments with
a gap before 09:59:50. This tests late session arithmetic/seeking, **not** ten hours
of continuous capture or decoder throughput. Unit tests simulate decoder latency;
browser tests use real file decoding and sample rendered timecodes.

`camera-variable.webm` is a separate regression sample from the studio's synthetic
canvas/audio MediaRecorder test on Windows Chromium 151.0.7922.34 (2026-09-28).
It contains VP9/Opus at 320×180 with a nominal 30 fps, a recorded start offset of
0.00019999980926513672 s and a recorder-observed duration of 5.00460000038147 s.
Its variable cadence includes a frame from source time 2.410 to 2.531 s. Trimming
the common interval 0.5–2.5 s must retain that frame's remaining duration rather
than produce a video ending about 90 ms early. The prepared file explicitly uses
the recorded nominal cadence; embedded audio and original bytes remain separate.
This file contains only the same generated canvas/audio markers as the E2E test,
not physical camera/microphone input. `generate.mjs` regenerates only the three
deterministic timecode files above, not this captured regression sample.
