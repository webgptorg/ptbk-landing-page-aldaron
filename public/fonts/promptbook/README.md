# Promptbook fonts

Headings: Exo 2, weight 600. Body/UI: Barlow 400, emphasis 500-700.
The hero uses Exo 2 600, letter-spacing -0.025em and line-height 1.18.
The deployment subtitle uses Exo 2 500. Body text uses line-height 1.6.

Desktop: install Exo2-Variable.ttf and Barlow-*.ttf in your operating system
before editing the SVG slide/social templates. These are the same complete
font sources used for the website's WOFF2 files; Czech characters are included.

Web: keep fonts.css beside the WOFF2 files and include it with a stylesheet link.
Use font-family: "Exo 2", Arial, sans-serif for headings, and "Barlow", Arial,
sans-serif for body text. The brand.css file in the kit provides palette/type tokens.

Both families are distributed under SIL Open Font License 1.1. Keep exo2-OFL.txt,
barlow-OFL.txt and provenance.json with the fonts when redistributing them.
The outlined Promptbook wordmark is supplied as artwork; do not retype it.
